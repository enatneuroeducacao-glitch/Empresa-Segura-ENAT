# Empresa Segura ENAT

Portal público inicial do programa Empresa Segura ENAT, criado como projeto independente.

## Tecnologias
- React
- Vite
- Lucide React
- CSS responsivo

## Executar localmente
```bash
npm install
npm run dev
```

## Gerar versão de produção
```bash
npm run build
npm run preview
```

## Estado atual
Esta primeira etapa entrega a identidade visual e o portal público responsivo, com apresentação do programa, eixos de atuação e etapas de participação.

A área de empresa está intencionalmente identificada como em implantação. Ainda não existe autenticação, banco de dados, cadastro persistente, portal administrativo nem autorização de usuários. Esses recursos devem ser construídos e testados antes de disponibilizar dados empresariais.

## Publicação
Pode ser publicado como site estático em um serviço compatível com Vite. Comando de build: `npm run build`. Diretório publicado: `dist`.
